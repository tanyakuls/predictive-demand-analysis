# Predictive Demand Analysis 

## 📊 Project Overview

This project focuses on analyzing and predicting demand and growth patterns for EduPro using Power BI and structured business data.

The objective is to transform raw data into meaningful insights that can support data-driven business decisions.

## 🎯 Objectives

* Analyze transaction and user data.
* Identify demand and growth trends.
* Understand course and teacher performance.
* Develop interactive Power BI dashboards.
* Generate actionable business insights.

## 🛠️ Tools & Technologies

* **Power BI** – Data modeling, analysis, visualization, and dashboard development
* **CSV** – Source data
* **DAX** – Calculations and measures
* **Power Query** – Data preparation and transformation
